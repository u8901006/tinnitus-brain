# Tinnitus Brain · 耳鳴研究文獻日報

自動從 PubMed 抓取最新耳鳴／聽覺神經科學研究文獻，由 AI 分析總結，每日生成研究日報。

## 特色

- 🔍 **多面向搜尋**：涵蓋耳鳴機制、聽覺神經科學、心理治療、體感耳鳴、營養、運動、神經調節、流行病學等主題
- 🤖 **AI 分析**：使用 Zhipu GLM-5-Turbo 進行文獻摘要、分類、PICO 分析
- 📊 **每日日報**：自動生成 HTML 網頁，部署至 GitHub Pages
- 🏥 **臨床連結**：每篇日報底部附有李政洋身心診所連結

## 技術架構

- **GitHub Actions**：每日 08:45 (台北時間) 自動執行
- **PubMed E-utilities**：文獻搜尋與擷取
- **Zhipu AI (GLM-5-Turbo)**：文獻分析與摘要
- **GitHub Pages**：靜態網頁託管
